# 怎么让同学打开你的系统（照做即可）

> 演示账号：**demo2023 / demo1234**（已创建，学生权限，看不到审核台）
> 管理员账号请自己留着：20230003 / abc12345

---

## 第 0 步：确认系统在跑

打开 PowerShell，执行：

```powershell
Invoke-RestMethod http://127.0.0.1:8080/actuator/health
```

看到 `status : UP` 就说明服务正常。如果报错，先启动：

```powershell
powershell -File "C:\Users\saxtul\Documents\ds harness区\知屿校园\software\start-mysql.ps1"
java -jar "C:\Users\saxtul\Documents\ds harness区\知屿校园\software\campus\target\campus-0.0.1-SNAPSHOT.jar"
```

---

## 第 1 步：查你现在的 IP

```powershell
ipconfig | Select-String "IPv4"
```

你会看到类似 `10.30.14.204`。

**这个 IP 会变**（换 WiFi、重连都会变），每次演示前都要重新查。

---

## 第 2 步：放行 8080 端口（需要管理员）

1. 按 `Win` 键，输入 `powershell`
2. **右键**「Windows PowerShell」→ **以管理员身份运行**
3. 在弹出的蓝色窗口里粘贴：

```powershell
New-NetFirewallRule -DisplayName "知屿校园-8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Any
```

看到输出里有 `Enabled : True` 就成功了。

> 只需要做一次，以后一直有效。
> 你的网络是「公用」类型，所以必须加 `-Profile Any`，否则规则不生效。

---

## 第 3 步：先用手机自测（关键）

手机连**和电脑同一个 WiFi**，浏览器打开：

```
http://10.30.14.204:8080
```

> 把 IP 换成第 1 步查到的那个。

**能看到登录页 = 成功**，直接跳到第 4 步。

**打不开 = 大概率是校园网的「客户端隔离」**（CMCC-WIT 这类运营商网络通常会禁止设备互访）。这种情况不要继续折腾，直接走下面的「方案 B」。

---

## 第 4 步：发给同学

把这两行发给他：

```
地址：http://10.30.14.204:8080
账号：demo2023　口令：demo1234
```

他可以做的事：浏览帖子、发帖、回帖、点赞收藏、检索、进聊天室发消息。

---

## 方案 B：手机开热点（校园网隔离时的首选）

比校园网稳得多，因为**你的电脑是热点的主人**，不存在设备隔离。

1. 手机打开「个人热点」
2. 电脑连这个热点，重新执行第 1 步查 IP（通常会变成 `192.168.43.x`）
3. 同学的手机/电脑也连同一个热点
4. 他把地址改成新 IP 访问

注意：走热点会消耗你的手机流量（页面本身很小，浏览文字几乎不费流量）。

---

## 方案 C：内网穿透（不同网络也能看，最稳）

适用：老师不在你身边、要发链接过去、或者上面两条都不通。

**不需要注册**，Cloudflare 免费提供临时域名：

1. 下载工具（约 30 MB，只需一次）：

```powershell
Invoke-WebRequest -Uri "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe" -OutFile "$env:USERPROFILE\cloudflared.exe"
```

2. 启动隧道（**这个窗口不能关**）：

```powershell
& "$env:USERPROFILE\cloudflared.exe" tunnel --url http://localhost:8080
```

3. 窗口里会打印一行地址，长这样：

```
https://random-words-1234.trycloudflare.com
```

**把这个 https 地址发给同学，任何网络都能打开。**

4. 用完按 `Ctrl + C` 关闭隧道，公网访问立即失效。

注意事项：
- 免费域名是随机的，**每次启动都不一样**
- 隧道开着的时候，**任何人拿到链接都能注册账号**，演示完记得关
- 速度取决于你的上行带宽，文字页面够用

## 排查清单

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 本机能开，别人打不开 | 防火墙 | 回到第 2 步，确认规则存在 |
| 同学打开一直转圈 | 校园网客户端隔离 | 改用方案 B 或 C |
| 昨天能开今天不行 | IP 变了 | 重新执行第 1 步 |
| 页面能开但登录报错 | 服务没连上数据库 | 检查 MySQL：`Get-Process mysqld` |
| 8080 被占用 | 开了两个实例 | `Get-NetTCPConnection -LocalPort 8080` 看进程，关掉多余的 |

---

## 提醒

- 同学用的是**真实的数据库**，他发的帖子会留在你的库里。演示前可以清一下，或者接受这些测试数据。
- 不要把**管理员账号**给同学，否则他能进审核台删你的内容。
- 电脑**不能休眠**，一休眠服务就断了（设置 → 电源 → 屏幕和睡眠 → 改为「从不」）。
